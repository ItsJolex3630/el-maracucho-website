# 🛒 ¡El Maracucho! · Abasto, Delivery y Pick Up - Sitio Web Oficial

Repositorio oficial y de producción para el despliegue de **¡El Maracucho! · Abasto, Delivery y Pick Up** en **Cloudflare Pages**.

## 🌐 Despliegue en Cloudflare Pages
- **Proyecto:** `el-maracucho-website`
- **Dominio Pages:** `https://el-maracucho-website.pages.dev`
- **Rama principal:** `main`

## 🔒 Reglas de Seguridad
- El archivo `.gitignore` protege rigurosamente cualquier variable de entorno (`.env*`).
- Ningún secret, token o credencial sensible debe subirse al repositorio.

## 📂 Contenido
- `index.html`: Landing page optimizada de alta conversión lista para producción.
- `wrangler.jsonc`: Configuración nativa para Cloudflare Pages.
